### 6.3 Testes E2E
#### Fluxo: seguranca administrativa (CT-21)
- **CA**: CA-16
- **Objetivo**: Verificar que pessoa sem sessao valida nao acessa listagens nem executa mutacoes administrativas.
- **Pré-condições**: Servidor Next em teste; nenhuma sessao Firebase Authentication valida.
- **Passos**:
  1. Acessar rotas administrativas sem sessao.
  2. Tentar acionar mutacoes administrativas.
  3. Consultar dados no emulador.
- **Validações**: redirecionamento, 401 ou 403; Firestore sem mutacoes.
