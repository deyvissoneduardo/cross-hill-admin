## 2. Objetivo da Task
Implementar a entrada publica minima para cliente consultar slots liberados/livres e solicitar agendamento usando as configuracoes de aparencia/texto.

---

## 3. Descrição Detalhada
- Modificar `app/page.tsx` para experiencia publica minima de disponibilidade/solicitacao ou entrada definida no Tech Spec.
- Criar componentes publicos para disponibilidade e formulario de solicitacao.
- Criar Server Actions publicas com superficie minima para consultar disponibilidade e solicitar agendamento.
- Usar `bookingService.requestAppointmentAtomically` para bloquear imediatamente o horario aceito.
- Aplicar cores/textos salvos via `settingsService`, sem permitir que cliente altere configuracoes.
- Garantir que slots ocupados, bloqueados ou nao liberados nao aparecam como solicitaveis.

### 3.1 Exemplo de Payload
N/A — sem payload parcial

## 4. Aceite Técnico
A task estará concluída quando:
- [ ] Cliente visualizar apenas slots liberados e desocupados.
- [ ] Solicitacao aceita tornar o slot indisponivel para outros clientes.
- [ ] Tentativa em slot bloqueado/ocupado falhar sem criar duplicidade.
- [ ] Cores/textos configurados forem refletidos na experiencia publica.
- [ ] Cliente nao tiver acesso a rotas/actions administrativas.
