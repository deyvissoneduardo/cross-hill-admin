## 4. Detalhes de Implementação

### 4.1 Contexto do Débito

**Origem**: task `T8` da `v1` — registrado em `docs/specs/features/painel-admin-agendamentos/v1/_run/run-report.md` (linha 185).

**Descrição original**: o terceiro servidor Next (emulado, porta 3101) sobe sem `--hostname`, escutando em `0.0.0.0`, com credencial de administrador de teste versionada em claro (`E2E_ADMIN_PASSWORD`). Durante uma execução de E2E, alguém na mesma rede (ou outro job num runner compartilhado) poderia autenticar-se nesse servidor efêmero com a senha do repositório. Efeito prático baixo (instância descartável, projeto `demo-*`).

**Categoria**: `security` (baixo)

**Classificação do especialista**: `recomendado_corrigir`
**Justificativa**: Confirmado: `npx next start --port ${EMULATED_PORT}` roda sem `--hostname` (bind `0.0.0.0`) com credencial de teste versionada; adicionar `--hostname localhost` é troca de uma string, risco baixo (ambiente local/CI single-machine), valor de segurança direto.
**Custo estimado**: ~1min
**Risco de regressão**: `baixo`

### 4.2 Correção

- [ ] No comando do `webServer` do servidor emulado (porta 3101, próximo à linha 182 de `playwright.config.ts`), adicionar a flag `--hostname localhost` ao `npx next start`. **Usar `localhost` (não `127.0.0.1`)** — preserva o motivo documentado do `baseURL`: o `APIRequestContext` do Playwright descarta cookie `Secure` sobre IP literal.

> Não há subtarefas adicionais. Cleanup é cirúrgico.

### 4.3 Guardrails de Execução

**DEVE**:

- Ler `docs/specs/features/painel-admin-agendamentos/v1/_run/run-report.md` ao redor da linha 185.
- Confirmar que `--hostname localhost` (não `127.0.0.1`) é usado, para não quebrar o mecanismo de cookie `Secure` já documentado no próprio `playwright.config.ts`.
- Rodar `npm run test:e2e` após a mudança para confirmar que o servidor emulado ainda inicia e os specs `admin-a11y.spec.ts`/`professional-surface.spec.ts` continuam passando.
- Reportar regressão imediatamente.

**NÃO DEVE**:

- NÃO alterar o servidor do CT-21 (porta 3100) nem o `webServer` de integração (fora do escopo deste débito — o próprio débito nota isso como "opcional" e não pedido aqui).
